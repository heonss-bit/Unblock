# Unblock (бета)

Одно маленькое окно, чтобы включать обход блокировок: **Запрет** для YouTube и Discord и **TG-прокси** для Telegram. Windows, написано на Rust, один exe, быстро запускается и почти не занимает памяти.

Приложение не изобретает обход заново, а управляет готовыми проектами [Flowseal](https://github.com/Flowseal): [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Всё скачивается с их официальных страниц при первом запуске.

> **Бета.** Проверена не на всех провайдерах. Если YouTube или Discord не открываются, нажми «Подобрать стратегию». Используй на свой риск.

## Скачать

Последняя версия: [Releases](../../releases/latest):

- `Unblock.exe` — программа (установка не нужна)
- `Unblock.exe.sha256` — контрольная сумма, чтобы проверить файл

Windows при первом запуске может показать предупреждение SmartScreen (нет платной подписи): «Подробнее» → «Выполнить в любом случае». Программа просит права администратора: без них драйвер, который меняет трафик, не запустится.

## Как пользоваться

1. Запусти `Unblock.exe`. При первом запуске он скачает запрет (zapret от Flowseal), нужен интернет. Заодно спросит, ставить ли TG-прокси: можно согласиться или отложить, скачать его можно в любой момент во вкладке «TG-прокси».
2. Нажми большую кнопку питания на странице **«Запрет»**. Работают YouTube и Discord.
3. Если что-то не открывается, нажми **«Подобрать стратегию»**: Unblock по очереди проверит все стратегии и отметит лучшую меткой «ЛУЧШАЯ» с кнопкой «Использовать?».
4. Для Telegram: вкладка **«TG-прокси»** → включить → «Открыть в Telegram».
5. Крестик окна убирает Unblock в **трей**, обход продолжает работать. Правый клик по значку: «Открыть Unblock», «Отключить обход», «Закрыть» (закрывает программу и отключает обход). Левый клик открывает окно.

## Окно

Слева колонка: «Запрет», «TG-прокси», «Настройки» и кнопка «Включить всё».

- **Запрет:** кнопка питания, плашка «YouTube · Discord» и список стратегий с проверкой.
- **TG-прокси:** кнопка питания для локального прокси Telegram Desktop (`127.0.0.1:1443`), «Открыть в Telegram», «Скопировать ссылку».
- **Настройки:** автозапуск с Windows, включение при запуске, сворачивание в трей при закрытии, тема и цвет акцента, обновление движков, папка с логами.

## Ограничения

- Только Windows 10 и 11, 64 бита.
- Само окно Unblock лёгкое, но TG WS Proxy от Flowseal написан на Python и занимает заметно больше памяти. Пока он выключен, нагрузки нет.
- У TG-прокси Flowseal остаётся собственная иконка в трее. Это часть его программы, скрыть её нельзя.
- Если у тебя уже запущен TG WS Proxy отдельно, закрой его: две копии одновременно не работают.
- Антивирусы иногда ругаются на драйвер WinDivert, который использует zapret (`RiskTool`). Это известная особенность проекта zapret, а не вирус. Проверяй, что скачиваешь, и бери только оригинал: на GitHub много поддельных сборок «zapret» с вирусами.
- Если запрет сразу выключается после включения, открой «Открыть папку с логами» и посмотри `zapret.log`.

## Где что лежит

Всё хранится в `%LOCALAPPDATA%\Unblock`: настройки, движки (`zapret`, `tg`) и логи. Чтобы удалить программу полностью, удали `Unblock.exe` и эту папку.

## Сборка

Rust + [egui](https://github.com/emilk/egui). Разбор стратегий zapret (`src/bat.rs`) покрыт тестами и проверен на всех файлах `general*.bat` из релиза Flowseal.

GitHub Actions: при каждом коммите в `main` собирается `Unblock.exe` и выкладывается релизом. Локально: `cargo build --release`.
