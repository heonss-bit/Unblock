## Unblock — БЕТА

Одно окно для обхода блокировок: «Запрет» (YouTube и Discord) и «TG-прокси» (Telegram). Windows, один exe.

**Это бета-версия.** Проверена не на всех провайдерах. Если что-то не открывается, нажми «Подобрать стратегию».

### Что скачать
- `Unblock.exe` — программа, установка не нужна
- `Unblock.exe.sha256` — контрольная сумма файла

### Что нового
- Крестик убирает программу в трей. Правый клик по значку: «Открыть», «Отключить обход», «Закрыть».
- Выбор «только YouTube / только Discord» убран: одна плашка «YouTube · Discord».
- Новый список стратегий и кнопка «Подобрать стратегию»: проверяет все по очереди, лучшую отмечает и предлагает «Использовать?».
- При первом запуске скачивается только запрет. TG-прокси ставится по желанию (вопрос задаётся один раз, потом скачать можно во вкладке «TG-прокси»).

### Установка
1. Скачай `Unblock.exe` и запусти. Windows может показать предупреждение (нет платной подписи): «Подробнее → Выполнить в любом случае».
2. Разреши запуск от администратора: без этого запрет не заработает.
3. Подожди, пока скачается запрет, и нажми кнопку питания.

### Перед использованием
- Антивирус может ругаться на драйвер WinDivert из zapret. Это известная особенность проекта. Проверяй файл по `Unblock.exe.sha256`.
- Если запрет сразу выключается, открой «Настройки → Открыть папку с логами» и посмотри `zapret.log`.
- Ты делаешь это на свой риск. Авторы ответственности не несут.
